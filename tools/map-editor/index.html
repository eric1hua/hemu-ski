Map editor

Click a tile, or drag a box.

Shift adds to the selection, Alt takes away.

Click a run to edit it.

Drag a point to move it. Double-click the line to add one, Alt-click a point (or hover it and press Del) to remove it.

Left-drag pans. In any tool, right-drag orbits, middle-drag (or Space + drag) pans, and the wheel zooms to the cursor.
