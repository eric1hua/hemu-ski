## 游戏接入

实现前读当前文件，保留其他人未提交修改。本段只指出接入约束，不假定旧代码未变。

- `src/main.js` 中地图加载和 `raiseBanks()` 后，站点、占位、terrain mesh 与碰撞须使用一致地形。
- `src/world/data.js` 的 Places 注册/过滤以及编辑器 `tools/map-editor/objects-view.js`
  要支持九类 ID。仅写 edits.places 中的未知 ID 不会自动显示；编辑位置/yaw后重载应保留。
- 新占位模块放 `src/world/`，配置放 `src/` 或 `public/`。父 `THREE.Group` ID和底心不变，
  以后用 GLB 替换子组。游戏不能从 `tools/summit-layout/` 导入生产文件。
- 碰撞按柱、框边、支腿与封闭体块拆开，保留相框空洞、秋千中央、pod架高底部的空间。
  将 footprint/top 接入玩家、车辆等实际共用的 obstacles，不仅做可见网格。
- 占位沿用现有 `makeToon`、描边、暖色日照/冷青灰阴影；实物身份先准确，细节从简。
- 不新增发布 HTML 入口；本次只处理游戏，独立 diorama 不声称自动同步。
